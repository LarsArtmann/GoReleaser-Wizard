# Domain Language

A **Unified Language** for GoReleaser-Wizard — shared across Customer, Product Owner, Developer, and AI.
Inspired by Domain-Driven Design (DDD) Ubiquitous Language.

Every term below should mean the **same thing** to everyone who reads it.
If a word means something different to a developer than to a customer, define it here.

## Glossary

| Term                   | Definition                                                                                                         | Context                                                             |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------- |
| Wizard                 | The CLI itself (`goreleaser-wizard`); both `init` (interactive) and `generate` (scriptable)                        | Product                                                             |
| Generation             | Producing config + workflow + Dockerfile artifacts in the user's repo                                              | Core capability                                                     |
| Atomic generation      | All target files are checked before any is written; a refusal leaves zero partial state                            | Generation safety property                                          |
| Placeholder            | Literal `owner`/`repo` in output when neither flags nor git remote could resolve the target                        | Must warn; a config that "checks green" but releases nowhere        |
| CI Provider            | Which workflow family + release targets a generation emits: `github`, `forgejo`, `dual`, `none`                    | `--ci-provider` flag; unset = github (byte-identical legacy output) |
| Forgejo mode           | `.forgejo/workflows/{ci,release}.yml` + `.goreleaser.yaml` with `gitea_urls`; releases target the Forgejo instance | In Forgejo Actions `secrets.GITHUB_TOKEN` IS the Forgejo API token  |
| Dual mode              | Both workflow sets generated; goreleaser still targets Forgejo                                                     | Public GitHub shadow + primary Forgejo                              |
| Release shadow         | Fleet-side script that copies Forgejo release assets to GitHub so the public mirror stays complete                 | SystemNix `forgejo-release-shadow`, not a wizard feature            |
| Dogfood config         | This repo's own `.goreleaser.yaml`, generated by the wizard and kept on v2.17                                      | Proof the product works on itself                                   |
| Pin                    | A deliberately frozen version (BuildFlow flake rev, goreleaser v2.17.1) rendered into workflows                    | Bumped deliberately, never floats                                   |
| Golden file            | Checked-in expected output of a generator; `-update-golden` regenerates byte-identically                           | Regression net for generated artifacts                              |
| Deprecation-free proof | The E2E gate: generated output must pass `goreleaser check` with exit 0 and zero deprecations                      | The product's definition of correct                                 |

## Entities

| Term              | Definition                                                                                                 | Context                                   |
| ----------------- | ---------------------------------------------------------------------------------------------------------- | ----------------------------------------- |
| SafeProjectConfig | The validated, defaulted heart of the domain: everything the wizard needs to generate                      | TypeSpec-generated; do not hand-edit      |
| Job               | A unit of generation work with Execute + Rollback                                                          | Workflow engine                           |
| Workflow          | An ordered set of jobs for one command path (full wizard vs config-only)                                   | JobFactory composes them                  |
| Generator         | Typed renderer for one artifact family (GoReleaser, GitHubActions, ForgejoWorkflows, Dockerfile, Homebrew) | The only code allowed to render templates |

## Value Objects

| Term                    | Definition                                                                         | Context                             |
| ----------------------- | ---------------------------------------------------------------------------------- | ----------------------------------- |
| ProjectType             | Enum: CLI Application, Web API, Library, gRPC, Microservice, Desktop, Daemon, Tool | Drives template shape               |
| Platform / Architecture | Enums for build targets; windows+arm64 is rejected as incompatible                 | Domain validation rule              |
| DockerSupport           | Enum: none, build-only, publish-only, build-and-publish                            | Gates `dockers_v2` + Dockerfile job |
| SigningLevel            | Enum for cosign/gpg configuration depth                                            | CI-side installer only today        |
| GitHubTarget            | Resolved owner/repo: flag > git remote > placeholder                               | `types/template_data.go`            |

## Events

| Term                      | Definition                                                         | Context                |
| ------------------------- | ------------------------------------------------------------------ | ---------------------- |
| GenerationPreflightPassed | All target-file existence checks passed before writing             | Atomic generation gate |
| JobRolledBack             | A failed job triggered removal of files written earlier in the run | Rollback support       |
