GoReleaser-Wizard is a short-lived, offline, subprocess-driven CLI wizard: zero net/http, no DB, no web UI (an explicit roadmap non-goal), no daemon, no event sourcing. Its only first-party dependency is go-branded-id v0.7.1. None of the 20 audited libraries is in use. 18 verdicts are structural stay-outs — the library's shape (service, HTTP, hypermedia, streaming, storage, daemon) simply does not intersect this binary. Two candidates earn a CONSIDER on real gaps: go-atomic-write (crash-safe file writes) and cmdguard (typed CLI + exit-code contract). 02Candidates

CONSIDER

go-atomic-write v0.6.2 — crash-safe file writes

cmd/goreleaser-wizard/generators/template_utils.go:24 · generators/goreleaser.go:85

All generator writes funnel through one choke point that calls bare os.WriteFile; a crash mid-write can truncate .goreleaser.yaml, and createBackup's rename-away leaves the target absent if the process dies before the rewrite. Temp+fsync+rename closes both windows per file and complements (not replaces) the preflight+rollback job-level atomicity. Two direct deps; golden tests unaffected.

Fix Swap os.WriteFile for atomicwrite.WriteWithPerm at the choke point (+2 stragglers), ~1–2 h. Escalate to ADOPT-NOW when files grow large, concurrent CI runs are supported, or rerun-idempotence becomes a documented feature.
CONSIDER

cmdguard v5.1.0 — typed CLI + exit-code contract

cmd/goreleaser-wizard/main.go:138-148 · generate.go:26-30

Typed struct-tag flags would replace ~15 hand-registered string flags and name-lookup reads, and the exit-code contract would fix the sharpest gap (see incidental findings). But the config layer is already solved on the same koanf versions, the huh wizard is richer than cmdguard's prompts submodule, and cmdguard pins charm.land/fang/v2 while this repo is on fang v1 — two majors in one binary unless fang migrates too. Migration: ~2–4 focused days.

Fix Do the cheap 90% locally now: switch handlers to RunE, propagate errors, exit on them. Adopt cmdguard/lint (CG001–CG008) into the lint pipeline immediately — zero runtime coupling, catches both defects below. Full migration when the command layer next changes shape.

Defect

Failed generate/init exits 0

cmd/goreleaser-wizard/generate.go:26-30 · main.go:332-337

Handlers are void Run: funcs that swallow errors via displayError(err); return — only validate sets a real exit code. A CI script consuming generate cannot detect failure. Routed to TODO_LIST.md.

Fix Convert handlers to RunE, propagate the error, exit non-zero on it. No new dependency required.
